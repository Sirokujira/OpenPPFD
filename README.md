# OpenPPFD

A radiative-transfer solver for **plant factory lighting** in C: photosynthetic
photon flux density (PPFD), spectral design, and canopy light distribution.
Companion project to [OpenFDTD](https://github.com/Sirokujira/OpenFDTD) — same
build conventions, same portability rules, no external libraries.

植物工場 (人工光型植物工場) の照明設計ソルバー (C 言語)。
[OpenFDTD](https://github.com/Sirokujira/OpenFDTD) の姉妹プロジェクトで、
ビルド規約・移植性規則を共有します。外部ライブラリ (HDF5/LAPACK/BLAS)
には依存しません。

## なぜ FDTD/RCWA と別なのか

植物工場の照明は**波動光学の問題ではありません**。扱うのは

- **光量子束密度 (PPFD)** — µmol/m²/s。エネルギー (W) ではなく光子の数
- **スペクトル設計** — 赤 660nm / 青 450nm / 遠赤 730nm の配分、R:FR 比
- **輻射伝達** — 反射壁での相互反射と、群落 (葉群) の Beer-Lambert 減衰

であって、波長スケールの構造による回折・干渉ではありません。したがって
FDTD (`OpenFDTD`) や RCWA (`OpenRCWA`) ではなく、光線・輻射伝達の枠組みで
解きます。

さらに、**一般照明の測光量がそのまま使えません**。一般照明は
lm / lx / lm/W (標準比視感度 V(λ) 基準、緑 555nm がピーク) ですが、
光合成は 400-700nm の光子を数え (PPFD)、量子収率は McCree 作用曲線
(赤 600-680nm がピーク) に従います。赤主体の園芸用 LED は
**lm/W では低く、µmol/J では高い**ので、一般照明の指標で評価すると
設計を誤ります。OpenPPFD は両方を必ず並べて出力します。

```
photon efficacy   =      2.69344 umol/J     <- 園芸用の指標
luminous efficacy =      63.8918 lm/W       <- 一般照明の指標 (同じ器具)
```

## Theory / 理論概要

1. **直接光** — 光源は配光 `I(θ) = Φ(m+1)/(2π) cos^m θ` (m=1 で Lambert、
   `iso` で等方) を持つ点光源。面光源は nu × nv 個の点光源へ分割します。
   実器具のカタログ配光 (IESNA LM-63 / EULUMDAT) も読めます
   (`ies` / `ldt` オプション)。ファイルから使うのは**配光の形だけ**で、
   放射束は入力ファイルの W 欄 (または `ppf` / `lumens`) から取ります
   — cd や lm は V(λ) 基準の測光量なので、SPD 抜きに W や µmol/s へは
   換算できないためです。配光は `∫Î dΩ = 1` に厳密に正規化するので、
   実測配光を使ってもエネルギー収支の検証はそのまま成り立ちます。
2. **相互反射** — チャンバ 6 面を矩形パッチに分割し、波長ビンごとに
   ラジオシティ方程式 `B_i = ρ_i (E_i^dir + Σ_j F_ij τ_ij B_j)` を
   Jacobi 反復で解きます。形態係数は「微小面 → 平面多角形」の閉形式を
   受光パッチ上で Gauss 求積したもの (放射側は厳密)。
3. **遮蔽物** — 棚板・トレイ・バッフルを軸並行直方体 (厚さ 0 の板も可) で、
   反射板・傾けたトレイを任意の向きの平行四辺形の板 (`panel`) で
   置けます。表面はパッチに分割されてラジオシティに参加し、直接光には
   2 値の影を落とします。多段ラックのように棚板が断面いっぱいの配置では
   パッチ対の可視率が 0 か 1 にしかならず、形態係数は遮蔽があっても
   厳密なままです (段どうしの分離が厳密に成り立つ)。
4. **群落** — 葉面積密度 a = LAI/厚さ、葉群投影係数 G の一様スラブ
   (断面全体、または栽培ベッドの上だけの箱) として、
   経路長 s に対し `τ = exp(-G a s sqrt(1-ω_λ))`。ω_λ = 葉の反射率+透過率
   (Goudriaan の散乱補正) で、ω=0 のとき厳密な Beer-Lambert 則になります。
   赤・青は強く吸収され、緑と遠赤は群落深部まで届きます。
   壁パッチどうしの交換では、対の中で経路長がばらつく (exp の凸性で
   重心の 1 本では過小評価になる) ので、経路長の分布を 2 点 Gauss 則
   `τ ≈ w₁e^{-ks₁} + (1-w₁)e^{-ks₂}` で持ちます。
   `leafscatter = on` にすると葉が散乱した光をキャビティへ戻します
   (下記)。
5. **測定面** — 水平・上向きの量子センサ相当。各セルで直接光 + 壁からの
   間接光を合成し、PPFD / YPFD / ePAR / lx / DLI / R:FR を出します。

### 現在の制限

決定論の解法 (Lambert 面のラジオシティ + 鏡像法 + 層別二流) の外にあるもの
は、**モンテカルロ光子追跡** (`montecarlo`、下記) で扱います :

- **一般の反射 (光沢)** : ラジオシティはパッチの放射輝度が向きによらない
  ことを前提にしているので、決定論の解法は Lambert 拡散 + 軸並行壁の鏡面
  反射だけです。光沢 (`glossy`) と棚板・板の鏡面は `montecarlo` で扱えます
  (光沢の指数を大きくすると鏡面に一致することを検証しています)。
- **群落の横方向の散乱** : 決定論の `leafscatter` は鉛直 1 次元の二流なので、
  群落に埋もれた側壁やベッドの側面との横のやりとりを表現しません (収支は
  保存。側壁が完全鏡面なら厳密)。`montecarlo` は群落の中の散乱を 3 次元で
  追うので、通路へ出る散乱光も入ります (検証 (ab) : 通路の鉛直面が黒葉より
  24% 明るい。決定論では黒葉と同じ)。
- 光子追跡の結果には統計誤差 (セルあたり `1/√(個数)`) があり、光沢の材料は
  `montecarlo` のときだけ使えます。

近似していて、その大きさをログ・検証で示しているもの :

- 曲面 (管・半割りの反射フード) は `cylinder` で内接する板の多角形に近似
  します (弦と円弧のずれ = サジタをログに出します)。幾何はそれ以外は
  **直方体チャンバ 1 個 + 軸並行の遮蔽物 + 平らな斜めの板** (`panel`) です。
- 部分的にしか遮られないパッチ対の可視率は標本化 (最大 4×4 × 4×4) で
  求めます。標本化に落ちた対の数は `ppfd.log` に出ます。
- パッチ間 (と測定面 → パッチ) の群落透過率は、パッチ対の中の経路長の
  分布を 2 点 Gauss 則に縮めて評価します (0〜3 次のモーメントを再現。
  平行平板の拡散透過 2E₃(τ₀) で 1e-4 以下)。
- 鏡像は `specbounce` 段で打ち切ります (向かい合う鏡面の連鎖は段数を
  上げると収束。変換が 512 個を超える段数は下げてログに出します)。
- 組み込みの McCree 作用曲線は公表曲線の**近似値**です
  (`actionspectrum = file` で上書きしてください。下記参照)。

入力の組み合わせの制約 (黙って誤差を出さないよう入力段で弾くもの) :

- 鏡面を運ぶのは**チャンバの壁だけ**です (棚板・斜めの板に鏡面の材料は不可)。
  鏡面壁は群落・遮蔽物・`leafscatter` のどれとも、どの面でも併用できます。
- 段ごとに違う葉材料は `leafscatter = on` のときだけ置けます。
- `leafscatter` + 栽培ベッド : 同じ段のベッドは同じ高さ範囲、別の段とは
  断面いっぱいの棚板で仕切る、床・天井の鏡面とは併用不可。
- `leafscatter` で群落の上面・下面を床・天井・棚板・トレイの面にそのまま
  乗せるときは、その面が群落の範囲を**全部**覆うこと (一部だけ乗る配置は
  エラー。すき間を空けるか、トレイを群落の範囲に合わせる)。

## Build / ビルド

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"

# 検証 (すべて解析解・定義値との比較)
sh data/sample/ppfd_check.sh bin/oppfd /tmp/ppfd-check
```

- Linux / macOS / Windows (MSVC + Ninja) の 3 OS を CI で検証しています。
- OpenMP は任意です (見つかれば形態係数・直接光・測定面を並列化。
  無くてもビルド・実行可能)。

## Usage / 実行

```bash
oppfd [-n <threads>] input.ppfd
```

出力 (カレントディレクトリ):

| ファイル | 内容 |
|---|---|
| `ppfd.log` | 実行ログ。器具の総量・エネルギー収支・測定面ごとの表。`=== normal end ===` で正常終了 |
| `ppfd_summary.csv` | 測定面ごとの 1 行要約 (平均/最小/最大 PPFD、均斉度、DLI、YPFD、lx、R:FR) |
| `ppfd_map_<target>.csv` | 測定面のセルごとの分布 (GUI での等高線表示用) |
| `ppfd_spectrum.csv` | 測定面の面平均スペクトル + 作用曲線 + V(λ) |

## Input format / 入力形式

テキスト形式。1 行目は `OpenPPFD 1 0`、最終行は `end`。`#` はコメント行。
書式は `キー = 値...`。単位は長さ [m]、波長 [nm]、放射束 [W]。
**未知のキーは無視されます** (前方互換)。**省略時の既定値は、キーを
書かない場合と挙動が一致する**よう選んであります (後方互換)。

### 解析条件

| キー | 書式 | 既定 |
|---|---|---|
| `title` | `title = 任意文字列` | 空 |
| `wavelength` | `wavelength = λ開始 λ終了 Δλ` | `380 780 5` |
| `chamber` | `chamber = Lx Ly Lz` | `1 1 1` |
| `patchdiv` | `patchdiv = nu nv` (1 面あたりの分割数) | `6 6` |
| `photoperiod` | `photoperiod = 時間/日` (DLI 用) | `16` |
| `solver` | `solver = 最大反復数 収束判定` | `200 1e-6` |
| `quadrature` | `quadrature = msub` (パッチ直接光の複合分割数、0=自動) | `0` |
| `specbounce` | `specbounce = N` (鏡面反射の鏡像段数。変換が 512 個に収まる段数へ自動で下げ、下げたらログに出す) | `2` |
| `actionspectrum` | `actionspectrum = file <path>` | 組み込み McCree |
| `montecarlo` | `montecarlo = <光子数> [種]` (決定論の解法の代わりに光子追跡で解く。下記) | 使わない |

### 材料 (Lambert 拡散面 / 葉)

```
material = <名前> gray  <ρ> [τ]
material = <名前> table <λ:ρ[:τ]> <λ:ρ[:τ]> ...
material = <名前> file  <path>            # "λ ρ [τ]" のテキスト
```

τ (透過率) は群落の葉材料でのみ使い、散乱係数 ω = ρ + τ になります。
テーブルは線形補間、範囲外は端の値でクランプします。

### スペクトル

```
spectrum = <名前> mono      <λ>                        # 単色
spectrum = <名前> gauss     <中心λ> <半値全幅>
spectrum = <名前> sum       <中心λ> <半値全幅> <重み> ...  # 3 つ組の繰り返し (白色 LED 等)
spectrum = <名前> blackbody <T[K]>
spectrum = <名前> table     <λ:値> ...                  # 分光放射束密度 [/nm 相対]
spectrum = <名前> file      <path>                      # "λ 値" のテキスト (実測 SPD)
```

内部では波長ビンごとの重み (総和 1) として保持します。ピークの 1e-10 未満の
裾は切り落として再正規化するので、放射束は厳密に保存されます。

### 光源

```
led   = <x> <y> <z> <放射束W> <スペクトル名> [オプション]
array = <x0> <y0> <z> <nx> <ny> <ピッチx> <ピッチy> <1灯あたり放射束W> <スペクトル名> [オプション]
```

| オプション | 意味 | 既定 |
|---|---|---|
| `beam <m>` | 配光 `I ∝ cos^m θ` | `1` (Lambert) |
| `iso` | 等方 `I = Φ/4π` | — |
| `ies <path>` | IESNA LM-63 の実測配光ファイル | — |
| `ldt <path>` | EULUMDAT の実測配光ファイル | — |
| `rot <deg>` | 配光を配光軸まわりに回す (`ies`/`ldt` 用) | `0` |
| `dir <dx> <dy> <dz>` | 配光軸 | `0 0 -1` (真下) |
| `size <w> <h> [nu nv]` | 面光源の寸法と分割数 | 点光源 |
| `ppf <µmol/s>` | 放射束をカタログの PPF で与える (W 欄より優先) | — |
| `lumens <lm>` | 放射束をカタログの光束で与える (W 欄より優先) | — |
| `input <W>` | 消費電力 (µmol/J・lm/W の算出に使う) | 未指定 |

#### 実測配光ファイル (IES / EULUMDAT)

```
led = 0.6 0.3 0.4 0 spd_red ies bar660.ies ppf 250 input 90
```

- 使うのは**配光の形だけ**です。ファイル中の cd / lm は放射束の決定には
  使いません (SPD 抜きに lm → W → µmol/s は決まらないため)。放射束は
  W 欄か `ppf` / `lumens` オプションで与えてください。ファイル記載の
  定格光束は参考値として `ppfd.log` に出ます。
- 角度の定義は IES 光度分布型 C / EULUMDAT と同じで、γ = 0 が配光軸
  (`dir`、既定は真下)。C 面は既定の `dir` のとき **C = 0 が +x、
  C = 90 が +y** で、`rot <deg>` で器具を配光軸まわりに回せます。
- IES は水平角の対称性 (0-90 / 0-180 / 0-360)、EULUMDAT は
  `Isym` = 0/1/2/3/4 を展開します。表の γ 範囲外の光度は 0 です。
- 配光は `∫Î dΩ = 1` へ正規化します。この積分は双線形補間の**厳密な**
  積分 (γ 方向は `∫(a+bγ)sinγ dγ` の閉形式) で評価するので、台形則の
  O(Δγ²) 誤差が放射束に漏れません。実測配光でも `closure error` は
  1e-6 のままです。
- 光度分布型 **A / B** (IES の投光器・車載の座標) も読めます。器具の座標は
  x = 配光軸 (`dir`)、z = 上 (+z を配光軸に直交させた向き。配光軸が鉛直なら
  C = 0 の向き)、y = z × x で、`rot` はこれを配光軸まわりに回します。
  型 A は V = 仰角・H = 上の軸まわりの方位角 (`dΩ = cos V dV dH`)、型 B は
  V = 横軸 y まわりの面の回転角・H = 横軸への緯度 (`dΩ = cos H dH dV`)。
  0..90° だけ書かれた角は鏡映で -90..90° へ展開し、正規化 `∫Î dΩ = 1` は
  型 C と同じく双線形の表の厳密な積分です。

### 壁・遮蔽物・群落・測定面・帯域

```
wall     = <面> <材料名> [div <nu> <nv>]   # 面 = xmin/xmax/ymin/ymax/zmin(floor)/zmax(ceiling)/side/all
occluder = <名前> <x0> <x1> <y0> <y1> <z0> <z1> <材料名> [div <nu> <nv>]
panel    = <名前> <p0 xyz> <p1 xyz> <p3 xyz> <材料名> [div <nu> <nv>]   # 斜めの板
cylinder = <名前> <軸の始点 xyz> <軸の終点 xyz> <R> <面数> <材料名> [arc <a0> <a1>] [div <nu> <nv>]   # 管・円弧
canopy   = <ztop> <zbot> <LAI> <G> <葉材料名> [<x0> <x1> <y0> <y1>]   # 複数行で多段ラックの各段 / 栽培ベッドごと
leafscatter = on | off          # 群落の散乱光をキャビティへ戻す (既定 off)
leaflayers  = <N>               # 二流の層数 (既定 8)
target   = <名前> <z> <nx> <ny> [<x0> <x1> <y0> <y1>]          # 水平・上向き
sensor   = <名前> <p0 xyz> <p1 xyz> <p3 xyz> <nu> <nv>          # 任意の向き
band     = <名前> <λ1> <λ2>     # 光量子束の割合を出す帯域 (既定 : UV-A/青/緑/赤/遠赤)
```

`wall` を書かない面は完全吸収 (ρ=0) です。`wall` の `div` はその面だけの
パッチ分割数 (省略時は `patchdiv`) で、`nu` / `nv` の向きは面ごとに
xmin : (y, z)、xmax : (z, y)、ymin : (z, x)、ymax : (x, z)、
floor : (x, y)、ceiling : (y, x) です。`target` の範囲を省略すると
チャンバの床面全体になります。

#### 任意の向きの測定面 (`sensor`)

`target` は水平で上向きの面です。壁面栽培 (垂直農法) の垂直面、葉の側面、
床の照り返しを見る下向きのセンサなどは `sensor` で置きます。

```
sensor = wall  1.2 0 0    1.2 0 0.45   1.2 0.6 0   12 9    # x = 1.2 の側壁沿い、-x 向き
sensor = under 0 0 0.3    0 0.6 0.3    1.2 0 0.3   24 12   # z = 0.3 の下向き
```

隅 `p0` と隣り合う 2 隅 `p1` (u 辺の端), `p3` (v 辺の端) の平行四辺形で、
**受光するのは `(p1 − p0) × (p3 − p0)` の側**です (`nu`, `nv` は u, v 方向の
分割数)。直接光・壁の相互反射・群落の減衰・鏡面の鏡像・遮蔽物の影は
`target` と同じに扱います。チャンバからはみ出す面や 3 隅が一直線に並ぶ
面は入力段でエラーにします。

`leafscatter = on` の群落の**内部**では、二流近似の上下の拡散流束 F↓, F↑
から、天頂から角 β だけ傾いた面の拡散放射照度を

```
E = F↓ (1 + cos β)/2 + F↑ (1 − cos β)/2
```

とします (二流近似では各半球の放射輝度が一様なので厳密)。上向きは F↓、
下向きは F↑、鉛直はその平均です。

出力の `ppfd_map_<名前>.csv` は 5 列目が PPFD で `target` と同じです。
`sensor` では 3, 4 列目が面内の座標 u, v [m] になり、セル中心の
x, y, z を末尾に足します。

#### 多段ラック : 段ごとの群落

`canopy` を複数行書くと、段ごとに別々の群落スラブを置けます。段ごとに
高さ範囲・LAI・葉群投影係数 `G` を変えられます (生育ステージの違い)。

```
occluder = shelf 0.0 1.2 0.0 0.6 0.45 0.45 tray   # 段を仕切る棚板
canopy   = 0.70 0.50 1.2 0.5 leaf                 # 上段 (若い株)
canopy   = 0.25 0.05 2.5 0.5 leaf                 # 下段 (収穫期)
```

減衰は段ごとの寄与の和 `τ = Σⱼ Gⱼ aⱼ sⱼ` (`aⱼ` = 葉面積密度、`sⱼ` =
その段を通った長さ) になります。鉛直な光線なら `sⱼ` は各段の厚みなので
`τ = Σⱼ Gⱼ LAIⱼ` です。

**葉材料**は、散乱なし (`leafscatter = off`) では全段で共通です。減衰は
`exp(-Σⱼ Gⱼ aⱼ √(1-ωⱼ) sⱼ)` なので、段ごとに `ω` が違うと波長ごとの重みも
段ごとに変わり、パッチ対の経路長を 1 個のスカラにまとめられなくなるため
です (入力段でエラー)。`leafscatter = on` ならビームは素の遮断 `k = G a`
(波長によらない) で運び、`ω` は段ごとの二流のカラムにしか現れないので、
**段ごとに違う葉材料** (段ごとに違う作物) を置けます。スラブどうしの
**重なり**は、同じ葉を二重に数えるのでエラーです (接するのは可)。

`leafscatter = on` の二流散乱場は**スラブごとに 1 本の鉛直カラム**として
解きます (層は通し番号 `g = j × leaflayers + m`)。隣り合うスラブの
**向かい合う面どうし**は拡散光をやりとりします : スラブ j の下面から出た
光のうちスラブ j+1 の上面へそのまま届く割合 (間のすき間の側壁・棚板は
形態係数と可視率で効く。面が接していれば 1) が、相手のカラムの境界からの
拡散入射になります。ある面を見るパッチと測定面は、隣のスラブの手前まで
です (向こうは隣のスラブの面が断面全体をふさぐ)。やりとりは反射の反復の
中で整合させ、面の流束の変化も収束判定に入れます。検証は

- 「棚板で仕切った 2 段 = 各段を独立なチャンバとして解いたもの」
  (測定面の分布がビット一致、群落・壁の吸収が和に一致)
- 「1 枚の群落を接する 2 枚に割っても同じ」(ビット一致)
- 「鏡面の天井と群落の間のすき間 = z で 2 倍にした幾何 (群落とその鏡像の
  2 枚が棚板なしで向かい合う)」(ビット一致)

で縛っています。

群落の上下面から出た散乱光をパッチと測定面へ配るときは、遮蔽物があれば
面を小矩形に割って可視率を掛けます (以前は掛けておらず、断面いっぱいの
棚板の上の測定面にも群落の散乱光が漏れていました)。

#### 栽培ベッドの上だけの群落 (水平範囲)

`canopy` の末尾に `x0 x1 y0 y1` を書くと、群落をその水平範囲 (栽培
ベッドの上) だけに置けます。省略すると従来どおり断面全体です。LAI は
**ベッドの床面積あたり**です。通路の上は葉が無いので、通路側へ斜めに
抜ける光は群落を一部しか通りません。

```
canopy = 0.25 0.05 3.0 0.5 leaf  0.05 0.55 0.05 0.55   # ベッド 1
canopy = 0.25 0.05 3.0 0.5 leaf  0.65 1.15 0.05 0.55   # ベッド 2 (間が通路)
```

- 経路長は線分と軸並行の箱の交差長 (slab 法) で厳密に求めます。
  鏡面壁と併用すると、鏡像への直線を通りうるチャンバの複製それぞれに
  ある「箱の鏡像」と照合します (遮蔽物と同じ考え方)。
- 範囲を断面全体にすると従来のスラブと同じ計算になり、結果は
  ビット一致します。接して並べたベッドも 1 枚のスラブと一致します
  (共有面に乗る光線を二重に数えないよう、箱は半開区間で判定します)。
- ベッドどうしの重なりはエラーです (接するのは可)。チャンバから
  はみ出す範囲もエラーです。
- `leafscatter = on` では、ベッドごとに床面積 = ベッドの範囲の 1 本の
  二流カラムを解き、ベッドの上下の矩形でキャビティとやりとりします。光線の
  預け入れは、層の箱の中にある区間を光線に沿った順に並べて透過率を掛け継ぎ
  ます (光線はベッドの間を横にも動くので z だけでは層の順序が決まらない)。
  **ベッドの側面からの横方向の出入りは表現しません** (断面全体のスラブの
  埋没パッチと同じ近似で、収支は閉じます。通路にいる測定面はベッドの側面
  からの散乱光を受けません)。同じ段に並ぶベッドは同じ高さ範囲、別の段との
  間には断面いっぱいの棚板が要ります。床・天井の鏡面との併用は入力段で
  エラーにします。検証は「対称な 2 つのベッド = 断面全体の 1 枚」「鏡面の
  側壁の隣のベッド = x 方向に 2 倍 (ベッドが 2 つ並ぶ)」の等価性 (ビット
  一致) で縛っています。
- 群落 (ベッドでも断面全体でも) は床・棚板・トレイの上に**そのまま乗せ
  られます** (`zbot` = 床 0 や棚板の高さ)。面と同一平面で向かい合う面が
  群落の範囲を全部覆うとき、面から出る散乱光はその下 (上) のパッチが重なりの
  割合でそのまま受け、面はほかのどこからも見えません。一部だけ覆う配置は
  エラーです。

#### モンテカルロ光子追跡 (`montecarlo`)

```
montecarlo = 4000000 7                       # 光子 400 万個、乱数の種 7
material   = film gray 0.05 glossy 0.85 50   # 光沢 (Phong ローブ cos^50、montecarlo のみ)
```

決定論の解法 (ラジオシティ + 鏡像法 + 層別二流) の外にある 2 つを扱う
ための、別の解き方です :

- **一般の反射** : Lambert 拡散 (`gray` 等) + 鏡面 (`specular <ρs>`) + 光沢
  (`glossy <ρg> <n>` : 鏡面の向きのまわりの `cos^n` ローブ。面の下へ出た分は
  その面が吸収) を、壁・棚板・斜めの板・管のどの面でも。ラジオシティは放射
  輝度が向きによらない前提なので、光沢の材料は `montecarlo` のときだけ受け
  付けます (棚板・板の鏡面も光子追跡なら扱えます)。
- **群落の 3 次元の散乱** : 光子は群落の中で素の遮断 `k = G a` で止まり、
  葉の `ω(λ) = ρ + τ` の確率で等方に散乱します (β = 1/2 の二流が近似して
  いる過程そのもの)。ベッドの側面から通路へ出る光や、群落に埋もれた側壁との
  横方向のやりとりもそのまま入ります。

光子は全部同じ重み `Φ/N` で (光源は放射束の比、波長ビンはスペクトルの重みで
確率的に選ぶ)、集計は光子の数 (整数) なので、**スレッド数によらず出力が
ビット一致**します。光子は必ずどこかで吸収されるので、**収支は厳密に閉じ
ます** (ずれは相互作用の上限 10 万回で打ち切った光子だけ。ログに出ます)。

決定論の解法との違い :

- 測定面の値は**セル平均** (決定論はセル中心の値)。統計誤差はセルあたり
  `1/√(個数)` で、測定面ごとの光子数をログに出します。
- 群落は常に散乱を含みます (`leafscatter` の有無によらない)。
- 鏡面は実際に反射させるので、鏡像の打ち切り (`specbounce`) はありません。
- 計算時間は光子数に比例します (400 万個で 1 秒前後)。

#### 鏡面反射する壁 (`specular`)

```
material = mirrorfilm gray 0.05 specular 0.90
```

材料の末尾に `specular <ρs>` を付けると、その面は `ρs` を**鏡面反射**します
(拡散反射 `ρd` とは別枠。吸収は `1 − ρd − ρs`)。チャンバは軸並行の直方体
なので、鏡面壁は**光源の鏡像**と等価です — 直接光についてはこれで厳密で、
近似は鏡像の段数の打ち切りだけです。段数は `specbounce = <N>` (既定 2)、
打ち切りで捨てた放射束は `ppfd.log` に出ます。鏡面が 1 面だけなら鏡像は
自分自身の面で折り返さないので、`specbounce = 1` で厳密になります
(ログの `truncated` が 0)。

**鏡面が 2 面以上あるとき**も正しく数えます。直交する面の鏡映は可換
(`M_zmax M_xmax = M_xmax M_zmax`) なので、「折り返した面の並び」で鏡像を
列挙すると角の鏡像を 2 回数えてしまいます。鏡映群は軸ごとの無限二面体群の
直積なので、鏡像は**軸ごとの展開指数** `n[3]` だけで一意に決まります :

| `n` | 折り返す面 | 座標 |
|---|---|---|
| `0` | なし | `c` |
| `n > 0` | max 面から交互に `n` 回 (xmax, xmin, …) | `n` 偶数 : `c + nL` / 奇数 : `(n+1)L − c` |
| `n < 0` | min 面から交互に `|n|` 回 | 同上 |

重みは交差する面の `Π ρs` です。たとえば `xmax` と `zmax` が完全鏡面で
`specbounce = 2` なら鏡像は 3 個 (x のみ / z のみ / 角) になり、反対側の面が
黒いので 3 段目の経路は消えて打ち切り放射束は厳密に 0 です。**同じ軸の
2 面**が鏡面のときは反射が無限に続くので、`specbounce` で打ち切った分が
`truncated` に出ます。

**拡散壁との混在**も正しく扱います。拡散壁からの放射が鏡面壁で正反射して
戻る経路は**拡張形態係数** (放射側パッチの鏡像) で運びます。軸並行の
直方体では鏡像パッチへの直線が必ず鏡面の矩形内で平面を横切るので、
この拡張は厳密です。検証は「完全鏡面の天井 = 鏡映した幾何 (高さ 2 倍 +
光源の鏡像)」の等価性で縛っており、両者はビット単位で一致します。
`ρd + ρs > 1` の非物理な材料は入力段でエラーにします。

**群落との併用** : 鏡面壁は**どの面でも**群落と両立します。鏡映は弧長を
保つので、群落内の経路長は「鏡像への直線の z が群落スラブの逆像に入って
いる割合 × 全長」に厳密に等しくなります。側壁 (x/y 面) の鏡映は z 座標を
保つので逆像はスラブそのもの (直線評価のまま厳密)。床・天井の鏡映は
スラブを動かしますが、鏡像への直線は箱型ビリヤードの展開そのものなので、
実経路の z は周期 `2Lz` の三角波

```
fold(z) = w        (w = z mod 2Lz, w <= Lz)
        = 2Lz - w  (w > Lz)
```

で厳密に得られます (床・天井で何回反射しても成り立ちます)。逆像は
`[zbot + 2kLz, ztop + 2kLz]` と `[2kLz - ztop, 2kLz - zbot]` の和です。
検証は「完全鏡面の壁 = その方向に 2 倍にした幾何」の等価性で縛っており、
側壁 (x 2 倍) も天井 (z 2 倍) も群落込みでビット単位に一致します
(この折り返しを落とすと天井のケースが 8.2% ずれます)。
**`leafscatter` との併用 (側壁の鏡面のみ)** : 側壁の鏡映は z を保つので、
鏡像への直線の z プロファイルは実経路と同じで、層への預け入れは展開した
直線のまま測れます。帳簿は「光線は止まった所で預ける」です :

- 鏡面のパッチに届いた光のうち、止まる (吸収または拡散反射) のは
  `1 − ρs` の分だけです。`ρs` の分は鏡像経路が展開した全経路を運んで
  預けるので、鏡面のパッチで終わる光線 (光源からの直接光、パッチ間の
  交換) の預け入れは `1 − ρs` 倍します。
- 群落の上下面から出た放射も鏡面で折り返します (面の鏡像への形態係数を
  `Π ρs` の重みで足す)。面から出た放射束が過不足なく止まるよう
  `Σᵢ Aᵢ (1 − ρsᵢ) Σₜ wₜ F(i → Tₜ(面)) = A_c` に正規化します。

完全鏡面ならこの帳簿は「鏡映した幾何を実在させた二重箱」と項ごとに一致
し、検証ではビット単位に一致します。

**床・天井の鏡面 + `leafscatter`** : 床・天井の鏡映は経路を z で折り返し、
層を通る順序を入れ替えます (下りの後に上り)。光源・パッチからの光線は、
展開した直線を `z = k Lz` の平面で区切って区間ごとに実チャンバへ戻し、
経路に沿った順に層へ預けます (透過率は区間をまたいで掛け継ぐ)。群落の
上下面から出た散乱光のうち、床・天井の鏡面で折り返して**そのまま同じ面へ
戻る**割合は、二流のカラムの**境界の反射率** (上面 `crtop`、下面 `crbot`) と
して入れます (面が鏡面の壁に乗っているなら `ρs` そのもの)。面の鏡像は、
上面なら天井で 1 回、下面なら床で 1 回折り返したものまでをパッチへ配り、
それより先の経路は必ず自分の面を通って群落へ戻るので境界の反射率が運び
ます。二流近似では完全反射の境界は鏡映した対称なカラムの中央面と等価なので、
検証は「鏡面の床に乗った群落 = z で鏡映して 2 倍にした幾何」の等価性
(ビット一致) で縛っています。

`ρs` は**波長非依存のスカラ**です。反射フィルムや研磨アルミはほぼ中性
なので、分光にせず 1 個の値で持ちます。

**遮蔽物との併用** : 鏡像からの直線は「折り返した経路」を表すので、
実在の棚板とだけ照合すると影を取りこぼします。たとえば光源 → 鏡面 →
センサの経路の **1 本目の脚** だけを遮る板は、鏡像からセンサへの直線には
当たりません (`mirror6.ppfd` では素の判定だと影が消えて +18.7%)。

鏡像への直線は箱型ビリヤードの展開なので、実経路は展開空間に並んだ
チャンバの**複製**を順に通ります。各軸の座標は直線上で単調なので、
通りうる複製は添字の箱 `[0..n0] × [0..n1] × [0..n2]` に収まります。
そこで、その複製それぞれにある**棚板の鏡像**と照合します。棚板の鏡像は
複製の内部にあるので、直線が通らない複製の鏡像に誤って当たることは
ありません。軸並行の箱は軸ごとの鏡映で軸並行の箱に移るので、判定は
従来の slab 法のまま厳密です。直接光・拡張形態係数の可視率・測定面の
鏡像項の 3 か所すべてにこの判定を使います。

#### 遮蔽物 (棚板・トレイ・バッフル)

`occluder` は軸並行の直方体です。**1 辺の長さを 0 にすると厚さ 0 の板**に
なり、表裏 2 面だけがパッチになります (棚板はこちらが確実)。表面は
`wall` と同じくラジオシティに参加するので、エネルギー収支は閉じたまま
です (`absorbed by walls` は遮蔽物の吸収を含みます)。`div` は 1 面あたりの
分割数で、省略時は `patchdiv` に従います。

置き方の注意 :

- **棚板の面が壁パッチの境界に乗るよう `patchdiv` を選ぶこと。** 例えば
  `chamber = 1.2 0.6 0.9` で棚板を z = 0.45 に置くなら `patchdiv = 8 8`
  (0.9 × 4/8 = 0.45)。パッチが棚板をまたぐと、そのパッチ 1 枚を通して
  上下段の間に光が漏れます。
- **遮蔽物の面を壁と同一平面で接触させないこと** (床の上に厚さのある箱を
  直に置く等)。同一平面のパッチどうしは互いに見えないものとして扱うので、
  その隙間の光が行き場を失います。床から浮かせるか厚さ 0 の板にします。
- 部分的にしか遮られないパッチ対の可視率は標本化で求めます。両端の外接箱が
  遮蔽物と重ならない対は標本を取らずに厳密に 1、重なる対は常に 256 本
  (点 → パッチは 16 本) の光線で数えます。標本の位置は無理数 (受光側は
  黄金比、放射側は √2 にもとづく位置) にずらしてあり、小数で書いた板の辺に
  光線がまとめて乗って結果が丸めで跳ぶことはありません。棚板が断面
  いっぱいの配置ではどの対も「全部見える / 全部見えない」に決まるので
  形態係数は厳密なままです。ログの
  `partially shadowed patch pairs` が 0 ならそうなっています。
- 影の境界ではパッチ求積の被積分関数が不連続になるため、境界にかかる
  パッチは自動的に分割を上げます (実行数はログに出ます)。境界にかかるかは
  粗い求積の点そのもの (ある光源が届く点と遮られる点の両方があるか) で
  判定します。それでも
  `closure error` は 1e-4 台が下限で、これは形態係数ではなく直接光の
  求積の限界です。部分的に影になる小さな板が反射率の高いキャビティに
  あると、可視率の標本化のぶん 1e-4〜1e-3 台になります (メッシュを細かく
  すると下がります)。

#### 管・円弧の面 (`cylinder`)

```
cylinder = pipe 0.5 0.0 0.30  0.5 0.6 0.30  0.02 16 white                 # 壁から壁まで渡した管
cylinder = hood 0.6 0.1 0.42  0.6 0.5 0.42  0.05 8 film arc -90 90       # 光源の上の半割りの反射フード
```

軸 (始点 → 終点)、半径 `R` の円柱を、内接する `面数` 枚の長方形の板
(`panel` と同じ両面の板) に分けて置きます。`arc a0 a1` [度] を書くと円弧
だけ (反射フード・半割りの管) になります。角度の基準 (0°) は軸に直交する
「上」(+z を軸に直交させた向き。軸が z に平行なら +x) で、向きは軸の
まわりの右ねじです (90° は軸 × 上)。両端は開いた管 (中空) です。分割の
既定は軸方向 `patchdiv`、弦方向 1。

曲面そのものではなく**内接多角形**なので、光線と軸の距離が `R cos(π/面数)`
より小さければ必ず遮られ、`R` より大きければ必ず通ります (その間は多角形の
向きで決まる)。弦と円弧の最大のずれ (サジタ `R(1 − cos(Δa/2))`) を
`ppfd.log` に出します。4 面・45° 始まりの筒は同じ断面の `occluder` の箱と
同じ遮蔽になります (箱は slab 法、板は平行四辺形の交差で判定するので、
辺をかすめる光線の分だけ 2.3e-4 違う)。

#### 斜めの板 (`panel`)

```
panel = refl  0.3 0.3 0.4   0.5 0.3 0.6   0.3 0.7 0.4   white div 4 4
```

隅 `p0` と、`p0` に隣り合う 2 隅 `p1` (u 辺の端) と `p3` (v 辺の端) で
**平行四辺形**を与えます (4 隅目は `p1 + p3 − p0`)。直交していなくても
構いません。厚さ 0 の**両面板**で、表 (`(p1 − p0) × (p3 − p0)` の向き) と
裏の 2 面がラジオシティに参加します。LED バーの脇の斜めの反射板や、
傾けたトレイを置くのに使います。`div` は u / v 方向の分割数です。

遮蔽判定は「線分と平行四辺形の交差」で行います。外接箱で代用しないので、
板の外接箱を通り抜けても板そのものに当たらない光線は遮られません
(`tiltpanel.ppfd` の点 b がちょうどその光線で、箱として扱うと誤って影に
なります)。鏡面壁と併用すると、板の鏡像 (3 隅を写した平行四辺形) と
照合して折り返した経路の影を判定します。

置き方の注意 :

- **チャンバの内側に収めること** (はみ出すと入力段でエラー)。
- 3 隅が一直線に並ぶ退化した板はエラーにします。
- 材料は拡散のみ。鏡面の材料はエラーにします (鏡面は壁だけが運ぶ)。
- 水平・鉛直な板は `occluder` の厚さ 0 の板と同じ結果になります
  (検証でビット一致を確認しています)。

### 作用曲線の差し替え

組み込みの McCree (1972) 相対量子収率は**公表曲線をディジタイズした
近似値** (誤差の目安 ±0.03、625nm で 1.0 に正規化) です。厳密な値が
必要な場合は

```
actionspectrum = file mccree.txt      # 各行 "λ[nm] 相対量子収率"
```

で上書きしてください。YPFD の検証は「625nm 単色なら YPFD = PPFD」という
曲線の値に依存しない構造的性質で行っているので、差し替えても検証は通ります。

よらず厳密に成り立つので、形態係数の求積誤差 (現状 1e-5) がそのまま
`closure error` に出ます。

## Example / 実用例

`data/sample/rack.ppfd` は栽培面 1.2 × 0.6 m のラック 1 段に、
赤/青/白/遠赤の LED バー 4 本 × 12 灯を配置し、LAI = 3 のレタス相当群落を
置いたものです。

```
--- source totals ---
radiant flux      =       39.504 W
PPF (400-700nm)   =      192.958 umol/s
luminous flux     =      4577.21 lm
input power       =        71.64 W
photon efficacy   =      2.69344 umol/J
luminous efficacy =      63.8918 lm/W

--- target "canopytop" (z = 0.25 m) ---
PPFD [umol/m2/s]             260.4
DLI [mol/m2/day]            15.001
uniformity min/avg          0.73445
R:FR (660/730)               15.311

--- target "canopybase" (z = 0.06 m) ---
PPFD [umol/m2/s]             32.65
R:FR (660/730)               5.124
```

群落を通ると PPFD が 1/8 に落ちる一方、R:FR は 15.3 → 5.1 まで下がります
(赤は葉に吸収され遠赤は透過するため)。これは徒長・光形態形成に直結する
量で、一般照明の lx では見えません。

### 多段ラック

`data/sample/rack2.ppfd` は同じ栽培面を 2 段にし、z = 0.45 m の棚板
(トレイ、ρ = 0.4) で仕切ったものです。棚板が無いと下段の LED の光が
上段へ回り込んでしまうので、多段ラックの設計には遮蔽判定が要ります。

```
--- target "tier2" (z = 0.5 m) ---      上段 (棚板の 5cm 上)
PPFD [umol/m2/s]             85.74
uniformity min/avg          0.81968

--- target "tier1" (z = 0.25 m) ---     下段 (群落上面)
PPFD [umol/m2/s]              63.46
uniformity min/avg           0.5899
```

同じ器具・同じ間隔でも、下段は群落の上面が反射の弱い葉であるぶん
均斉度が落ちます。上段の分布は下段の LED を消しても 1 ビットも
変わりません (棚板が断面いっぱいなので段どうしは厳密に独立)。
